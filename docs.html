Last updated: 16 November 2026

Where to find the app

  • Apps menu, Markdown Bridge: the full app with Import and Export.
  • Space sidebar, Markdown Bridge: the same app with the current space preselected.
  • Page menu (three dots), Export to Markdown: export the page you are on, with or without the pages under it.

Import Markdown into Confluence

  1. Open Markdown Bridge and stay on the Import tab.
  2. Drop files, a folder or a zip, or use the buttons.
  3. Choose the space. To place the pages under a specific page, type that page's exact title.
  4. Choose what happens when a title already exists: skip, update, or import as a copy.
  5. Check the page tree and any notes, then select Import.
  6. When it finishes, review the results and download the CSV report if you want a record.

How files become pages

In your filesIn Confluence
A Markdown file (.md, .markdown, .mdx)One page
A folderA parent page for the pages inside it
README.md, index.md or _index.md in a folderThe content of that folder's page
A folder with no such fileA page that lists its child pages
guide.md next to a guide/ folderThe folder's pages go under the Guide page

The page title comes from title in the front matter, then the first level 1 heading, then the file name. Titles must be unique in a space, so duplicates within one import get the parent's name added.

Front matter

An optional block at the top of a file:

---
title: Deployment guide
labels: [howto, platform]
confluence_id: 123456
---
  • title: the page title.
  • labels or tags: added as page labels.
  • confluence_id: written by exports. With "Update the existing page", the import writes back to that exact page.

Export Confluence to Markdown

  1. Open the Export tab, or use Export to Markdown in a page's menu.
  2. Choose the whole space, one page with everything under it, or one page only.
  3. Choose options, then select Export. The download starts when it finishes.

Options

  • Header block (front matter): adds title, page id, space, labels, source link and last updated time to each file.
  • Include images and files: saves attachments used in pages into an _attachments folder and links to them with relative paths. When off, images link to their Confluence address.
  • One file for AI tools: combines all exported pages into a single Markdown file with a source link under each page title.

What you get

A zip that mirrors the page tree. A page with child pages becomes a folder with a README.md. A page without children becomes page-title.md. A single page with no attachments downloads as one .md file.

Round trip

Export with the header block on, edit the files, then import the folder with "Update the existing page". Each file updates the page named by its confluence_id. Confluence keeps the previous version in page history.

Limits

  • Import: up to 2000 Markdown files, 5000 files in total and 300 MB per run. Single Markdown files up to 2 MB.
  • Export: single attachments over 25 MB are left out and listed in the results.
  • Pages that sit under a Confluence folder, whiteboard or database export as top-level files.
  • Large runs are paced by Confluence's rate limits. The app waits and retries by itself.
