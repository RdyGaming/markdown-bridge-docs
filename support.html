Common fixes

A page failed with "permission" in the message

The app uses your own Confluence permissions. Ask a space admin for permission to add pages and attachments in that space.

Some pages were skipped

Page titles are unique in a Confluence space. With the default setting, existing titles are skipped. Run the import again with "Update the existing page" or "Import as a copy".

An image is missing after import

The image file must be in the folder or zip you chose, at the path the Markdown points to. The report names each image that was not found.

A macro is missing from an export

Macros have no Markdown form. They are exported as comments such as <!-- Confluence macro: toc --> so you can see where they were.
