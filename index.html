Markdown in. Markdown out. For Confluence Cloud.

Markdown Bridge imports folders of Markdown files into Confluence as page trees, and exports pages or whole spaces as clean Markdown. One app for both directions.

What it does

  • Bulk import

    Drop a folder or a zip. Folders become parent pages, files become pages, and you see the full tree before anything is created.

  • Links and images kept

    Links between files become links between pages. Local images are uploaded as attachments.

  • Bulk export

    Export one page, a page tree, or a whole space, at any depth, as a zip that mirrors the page tree.

  • Ready for AI tools

    Combine a space into one Markdown file with source links for assistants and retrieval systems.

  • Errors do not stop the run

    If one page fails, the rest continue. A report lists every page and what happened.

  • Round trip

    Export, edit in your editor or Git, and import again to update the same pages.

Private by design

Markdown Bridge runs on Atlassian Forge and in your browser. It has no server of its own, stores nothing, and makes no requests outside Atlassian. It acts with your own Confluence permissions, so it can only read and change what you already can. Details are on the security page.

Questions

How do I import Markdown files into Confluence?

Open Markdown Bridge from the Apps menu, drop a folder or zip of Markdown files, choose a space and an optional parent page, check the page tree preview, and select Import.

How do I export a Confluence space to Markdown?

Open Markdown Bridge, go to Export, choose the space, and select Export. You get a zip with one Markdown file per page in the same tree as the space.

Does it send my content to an outside server?

No. There is no outside server.

Can I use exported Markdown with AI tools?

Yes. The single-file option produces one Markdown file with source links.

What Markdown is supported?

Headings, emphasis, lists, task lists, tables, code blocks with languages, block quotes, note and warning callouts, links, images and front matter. The docs list every conversion.
